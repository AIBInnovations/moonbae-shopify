# Odd Ritual — Shopify theme

A Shopify Online Store 2.0 theme converted from the Odd Ritual site, plus a static
preview of every template.

```
shopify-theme/   the theme — upload as a zip, or push with the Shopify CLI
preview/         static render of all 14 templates, open preview/index.html
reference/       styles.css from the original build (the source page itself is
                 47 MB of inlined base64 and is gitignored)
assets/          the placeholder SVGs the project started from
```

## Install

```sh
cd shopify-theme
zip -r ../odd-ritual-theme.zip assets config layout locales sections snippets templates
# Shopify admin → Online Store → Themes → Add theme → Upload zip file
```

or with the CLI:

```sh
shopify theme dev  --path shopify-theme
shopify theme push --path shopify-theme
```

## What's in it

* 26 sections, 27 snippets, 12 JSON templates, 146 assets.
* The design CSS ships unmodified (`assets/styles.css`, `assets/styles-2026.css`) and
  the original animation bundle runs as-is (`assets/scripts-2026.js`), with its
  libraries vendored under `assets/vendor-*.js` so there is no third-party runtime
  dependency.
* Editable: 181 section settings, 60 theme settings, 10 block types, 12 sections that
  can be added from the editor, and JSON templates so sections reorder and delete.
  Colour, typography and the grid are wired to the CSS custom properties the whole
  design is built on.
* Cart runs through the vendored Udesly bridge against Shopify's AJAX cart —
  add to cart opens the drawer, and Checkout hands off to Shopify's hosted checkout.

`shopify-theme/README.md` has the full section map and the deliberate differences
from the original.

## GitHub integration

Shopify's GitHub integration requires the theme at the root of a branch, so the
`shopify` branch mirrors `shopify-theme/` to its root. That branch is the one to
connect in Shopify admin → Online Store → Themes → Add theme → Connect from GitHub.

`.github/workflows/sync-shopify-branch.yml` pushes the mirror on every change to
`shopify-theme/` on main, so there is nothing to run by hand.

The store is connected to `AIBInnovations/moonbae`, not to this repo: Shopify's
GitHub App only lists repos *owned* by the account it is installed on, and the
store's GitHub connection is bound to the AIBInnovations account. Both repos hold
the same branches and the same sync workflow, so push main to both:

```sh
git push origin main && git push aib main
```

Shopify commits back to the `shopify` branch when settings change in the theme
editor. Those land at the branch root, so pull them into `shopify-theme/` before
the next sync overwrites them:

```sh
git fetch origin shopify
git show origin/shopify:config/settings_data.json > shopify-theme/config/settings_data.json
```

To pull the whole branch back instead of just the settings:

```sh
git fetch origin shopify && rm -rf shopify-theme && mkdir shopify-theme
git archive origin/shopify | tar -x -C shopify-theme
```

## Preview

`preview/` is generated by rendering the Liquid with mock Shopify data, then pointing
asset URLs at `../shopify-theme/assets` and rewriting internal links so the pages link
to each other. It cannot exercise add-to-cart or checkout — those need a real store.
